# Tool - Google Jules

**What it is:** Google's asynchronous coding agent. It clones a repository into a disposable virtual machine of its own, writes a plan you approve **before** any code is written, then works unattended and reports back through GitHub. Reads an `AGENTS.md` file for repository rules. Still labelled experimental.

**Why it matters to Jay:** the plan-approval-first bargain is the most conservative version of hands-off agent work — a useful model for tasks where Jay wants to sign off the approach, not just the result. The `AGENTS.md` convention it popularised now appears across the field, including in Hermes Agent.
