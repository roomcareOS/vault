# Tool - OpenAI Codex

**What it is:** OpenAI's agentic coding tool, defined by reach — the same agent in terminal, IDE, desktop, web and cloud, powered by the GPT-5.6 family (Sol/Terra/Luna tiers, chosen per session by cost). Safety design: a sandbox with a per-run permissions dial.

**Why it matters to Jay:** the main commercial alternative to [[Tool - Claude Code]] — usually rated the generalist (widest surfaces, cheapest entry) where Claude Code is the deeper programmable harness and [[Tool - Cursor]] the stronger in-editor experience. Many teams run more than one; worth knowing what the other half of the field looks like.
