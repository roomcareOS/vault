# Tool - Goose

**What it is:** an Apache-licensed, general-purpose agent (begun at Block, now Linux Foundation-governed) that runs on your own machine and works with 15+ model providers, including local ones. Not just for code: research, writing, data analysis and admin, extended through 70+ MCP connectors. Recipes (shareable YAML workflow files) turn a one-off session into something repeatable.

**Why it matters to Jay:** the closest thing to a desktop assistant with real hands that uses subscriptions he already pays for — and its recipes idea is the same "capture the workflow as a file" instinct as his own skills and runbooks.
