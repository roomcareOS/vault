# Tool - Devin

**What it is:** Cognition's cloud-based "AI software engineer" — the agent sold as a teammate: assign it a ticket, it works on its own machine, it comes back with a pull request. Billed in agent compute units (paying for work done, not seats), with its own cheaper in-house models.

**Why it matters to Jay:** the clearest example of the asynchronous, ticket-in/PR-out working model — the pattern Jay already uses when directing builds from a phone. Also a signal of where the field competes now: cost per task rather than raw capability.
