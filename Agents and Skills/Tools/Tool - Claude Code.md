# Tool - Claude Code

**What it is:** Anthropic's agentic coding tool — give it a goal and it reads the whole repository, edits files, runs commands and tests, and opens pull requests, from terminal, IDE, desktop, web or phone. Its conventions (`CLAUDE.md` project instructions, MCP tool connections, hooks, subagents) are the ones the rest of the field copies.

**Why it matters to Jay:** it is the tool that actually builds and operates his businesses — the working rules live in [[Claude Operating Profile - YFarmX]] and [[Claude Operating Profile - RoomCare]]. It sits at the centre of the field: rivals are measured against it, and even Grok's CLI reads its files ([[Research - Grok Build Mode (2026-07-28)]]).
