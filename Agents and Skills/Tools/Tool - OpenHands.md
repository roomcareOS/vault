# Tool - OpenHands

**What it is:** the MIT-licensed open-source agent platform (All Hands AI) — inspectable source, any model you point it at, deployable four ways (browser canvas, managed cloud, Python SDK, self-hosted Kubernetes). The default answer for organisations that will not send their codebase to somebody else's cloud.

**Why it matters to Jay:** proof of the pattern his stack already relies on — the hard part is now the model, not the wrapper, so open harnesses keep pace with commercial ones. Model-agnostic routing (expensive reasoning vs cheap routine work) is the same cost doctrine as the [[Hermes Newsroom Pipeline (YFarmX)]].
