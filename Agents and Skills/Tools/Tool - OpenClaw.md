# Tool - OpenClaw

**What it is:** the open-source autonomous agent (MIT-licensed, Peter Steinberger's project, now foundation-governed) that became the most-starred repository on GitHub in under five months. Self-hosted, any model, and you talk to it through Signal, Telegram, Discord or WhatsApp; it acts across files, shell, browser, email and calendar. Three-level skills system.

**Why it matters to Jay:** the breakout proof that messaging-first, self-hosted personal agents are mainstream — Microsoft now powers a Copilot personal agent with it ([[Research - Microsoft FY26 Model System (2026-07-30)]]), and China restricting it shows the risk side is real. The reference page is also one of [[YFarmX]]'s traffic-drawing explainers.
