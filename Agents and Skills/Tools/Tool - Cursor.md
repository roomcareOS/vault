# Tool - Cursor

**What it is:** the AI-native code editor from Anysphere — the agent that stayed inside the editor, so the developer watches every diff. Runs parallel and cloud agents, its own in-house Composer model, Bugbot for automated pull-request review, and Design Mode (point at the interface, the agent edits the code underneath).

**Why it matters to Jay:** the strongest in-editor option in the field his site covers, and its rules files (`.cursorrules`) have become a convention other agents — including Hermes Agent — read too. Design Mode is the pattern most relevant to a non-developer: directing visual changes without describing them in code terms.
