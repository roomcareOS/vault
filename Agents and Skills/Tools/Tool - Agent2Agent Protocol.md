# Tool - Agent2Agent Protocol

**What it is:** the open standard (Google-originated, Linux Foundation-stewarded, version 1.0 released) for agents talking to **each other** — discovering one another, delegating work and returning results without either side exposing its internal logic. The complement to [[Tool - Model Context Protocol]]: MCP gives agents hands, A2A gives them colleagues.

**Why it matters to Jay:** as his businesses run more agents ([[Hermes Newsroom Pipeline (YFarmX)]], operating profiles, per-business setups), A2A is the layer where they would eventually cooperate across vendors. The signal to watch is adoption, not the spec — eight rival companies sit on its steering committee.
